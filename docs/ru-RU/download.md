# Загрузки

LeviLauncher выпускается в версии для Windows и в версии для Android. Вкладка для вашего устройства выбирается автоматически.

=== "Windows"

    **Требования:** Windows 10 или 11 и лицензионная копия Minecraft Bedrock Edition (GDK / UWP) из Microsoft Store.

    - [Скачать установщик с GitHub Releases](https://github.com/LiteLDev/LeviLauncher/releases/latest)
    - [Зеркало Lanzou](https://levimc.lanzoue.com/b016ke39hc) — пароль `levi`; используйте его, если GitHub в вашем регионе работает медленно

    Далее: [Требования и установка](/ru-RU/guide/requirements-installation) · [Начало работы за 5 минут](/ru-RU/guide/quick-start)

=== "Android"

    **Требования:** Android 9.0 или новее на устройстве ARM64 и Minecraft Bedrock Edition 1.21.80 или новее из Google Play.

    - [Скачать APK с GitHub Releases](https://github.com/LiteLDev/LeviLaunchroid/releases/latest)

    Далее: [Getting Started](/ru-RU/android/guide/getting-started) (на английском)

::: info iOS
Версии LeviLauncher для iOS нет, и мы не планируем её выпускать.
:::

## Все выпуски

- Версия для Windows: [выпуски LiteLDev/LeviLauncher](https://github.com/LiteLDev/LeviLauncher/releases)
- Версия для Android: [выпуски LiteLDev/LeviLaunchroid](https://github.com/LiteLDev/LeviLaunchroid/releases)
