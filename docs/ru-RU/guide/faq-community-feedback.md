# ЧаВО, сообщество и обратная связь

## Часто задаваемые вопросы
### Нужно ли мне владеть Minecraft Bedrock?

Да. LeviLauncher предназначен для работы с легальной лицензионной копией Minecraft Bedrock Edition (GDK / UWP).

### Могу ли я использовать LeviLauncher на macOS или Linux?

У LeviLauncher есть версия для **Windows** и версия для **Android** ([руководство для Android](/ru-RU/guide/quick-start?platform=android)). Версий для macOS и Linux нет.

### Есть ли версия для iOS?

Нет. Мы не планируем выпускать LeviLauncher для iOS.

### Что выбрать: Release или Preview?

Используйте сборку Minecraft **Релиз** для обычной игры. Выбирайте сборку Minecraft **Предрелиз** (Preview) только тогда, когда вам конкретно нужны предстоящие функции и вы готовы к возможной нестабильности.

### Обязательна ли изоляция?

Нет, но она настоятельно рекомендуется для тестирования, сборок Minecraft Preview и настроек с модами. Изоляция доступна для версий GDK и для версий UWP x64 начиная с 1.19.70.2.

### Могу ли я управлять мирами и паками внутри лаунчера?

Да. LeviLauncher включает представления контента для миров, ресурс-паков, поведенческих паков, паков скинов, скриншотов и серверов.

### Могу ли я устанавливать моды?

Да, но работа с модами — это продвинутая область. Начните с чистой изолированной версии и тестируйте постепенно.

### Что нужно версии для Android?

Android 9.0 или новее на устройстве ARM64 и Minecraft Bedrock Edition 1.21.80 или новее, установленная из Google Play. См. [Требования и установка](./requirements-installation).

### Можно ли запускать несколько версий Minecraft на Android?

Да. Импортируйте официальные APK Minecraft, чтобы запускать другие версии внутри лаунчера, и включите изоляцию, чтобы их данные хранились раздельно.
