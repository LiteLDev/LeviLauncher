# 下载

LeviLauncher 提供 Windows 版和 Android 版，下方已自动选中适合你设备的版本。

=== "Windows"

    **要求：** Windows 10 或 11，以及从 Microsoft Store 获得的正版 Minecraft 基岩版（GDK / UWP）。

    - [从 GitHub Releases 下载安装程序](https://github.com/LiteLDev/LeviLauncher/releases/latest)
    - [蓝奏云镜像](https://levimc.lanzoue.com/b016ke39hc) — 密码 `levi`；GitHub 下载较慢时使用

    下一步：[在 Windows 上玩模组](https://levimc.org/tutorials/zh-Hans/play/play-with-mods/) · [版本管理](/zh-Hans/guide/version-management?platform=windows)

=== "Android"

    **要求：** Android 9.0 或更高版本的 ARM64 设备，以及从 Google Play 安装的 Minecraft 基岩版 1.21.80 或更高版本。

    - [从 GitHub Releases 下载 APK](https://github.com/LiteLDev/LeviLauncher-Android/releases/latest)

    下一步：[版本管理](/zh-Hans/guide/version-management?platform=android)

::: info iOS
LeviLauncher 没有 iOS 版，我们也没有开发 iOS 版的计划。
:::
