# Preguntas frecuentes, comunidad y comentarios

## Preguntas frecuentes

### ¿Es obligatorio tener la versión original de Minecraft Bedrock?

Sí. LeviLauncher está diseñado para usarse junto con **Minecraft Bedrock Edition (GDK / UWP) original**.

### ¿Se puede usar en macOS o Linux?

LeviLauncher tiene una versión para **Windows** y otra para **Android** ([guía de Android](/es-ES/guide/quick-start?platform=android)). No hay versión para macOS ni Linux.

### ¿Hay una versión para iOS?

No. No tenemos planes de crear una versión de LeviLauncher para iOS.

### ¿Debería elegir Release o Preview?

Para el juego diario, prioriza la versión **Lanzamiento** (Release) de Minecraft. Solo considera la versión **Vista previa** (Preview) si necesitas explícitamente probar contenido futuro y aceptas la inestabilidad.

### ¿Es obligatorio el aislamiento?

No es obligatorio, pero es muy recomendable para entornos de prueba, entornos de Minecraft de vista previa (Preview) y entornos con Mods. El aislamiento está disponible para las versiones GDK y para las versiones UWP x64 1.19.70.2 o posteriores.

### ¿Se pueden gestionar mundos y paquetes de recursos en el lanzador?

Sí. LeviLauncher proporciona vistas de contenido para mundos, paquetes de recursos, paquetes de comportamiento, paquetes de skins, capturas de pantalla y listas de servidores.

### ¿Se pueden instalar Mods?

Sí, pero se trata de un flujo de trabajo avanzado. Se recomienda empezar con una versión aislada limpia y probar gradualmente.

### ¿Qué necesita la versión para Android?

Android 9.0 o posterior en un dispositivo ARM64, y Minecraft Bedrock Edition 1.21.80 o posterior instalado desde Google Play. Consulta [Requisitos e instalación](./requirements-installation).

### ¿Puedo ejecutar varias versiones de Minecraft en Android?

Sí. Importa APK oficiales de Minecraft para ejecutar otras versiones dentro del lanzador y activa el aislamiento para mantener sus datos separados.

## Cómo informar de problemas y sugerencias de funciones

Utiliza [GitHub Issues](https://github.com/LiteLDev/LeviLauncher/issues) para informar de:

- Errores reproducibles
- Problemas de instalación claramente relacionados con LeviLauncher
- Sugerencias de mejora para la claridad de la documentación
- Solicitudes de funciones con un caso de uso claro

Los problemas de la versión para Android van a [LiteLDev/LeviLaunchroid Issues](https://github.com/LiteLDev/LeviLaunchroid/issues).

## Antes de enviar un Issue, se recomienda

- Actualizar a la última versión disponible
- Realizar una prueba de comparación con una versión aislada limpia
- Desactivar temporalmente los Mods o paquetes de recursos recién añadidos
- Registrar los pasos exactos que provocan el problema
