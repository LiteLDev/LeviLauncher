# Управление версиями

LeviLauncher рассматривает каждую установленную настройку как версию, которой можно управлять независимо. В приложении установленные версии называются инстансами и перечислены на странице **Инстансы**.

## Что вы можете делать

=== "Windows"

    - устанавливать сборки Minecraft Release или Preview
    - давать версиям понятные имена
    - быстро запускать выбранную версию
    - удалять версии, которые вам больше не нужны
    - открывать настройки конкретной версии
    - создавать ярлык на рабочем столе для версии

=== "Android"

    - импортировать официальные APK Minecraft и запускать их внутри лаунчера, не устанавливая каждую версию в систему
    - держать несколько версий и их данные раздельно
    - выбирать версию, которую запускает экран запуска

## Minecraft Release против Preview <Badge platform="windows" />

| Тип | Лучше всего подходит для | Примечания |
| --- | --- | --- |
| Release | Стабильной ежедневной игры | Рекомендуется для большинства игроков |
| Preview | Тестирования предстоящих изменений | Чаще может повреждать миры, паки или моды |

## Объяснение изоляции

=== "Windows"

    Изоляция доступна для версий GDK и для версий UWP x64 начиная с 1.19.70.2. Когда изоляция включена, LeviLauncher хранит управляемые игровые данные в собственном рабочем пространстве этой версии, вместо того чтобы позволять всему использовать одно и то же расположение данных по умолчанию.

    Изоляция полезна, если вы хотите:

    - разные наборы контента для разных версий
    - более безопасное тестирование модов или сборок Minecraft Preview
    - меньший риск влияния одной настройки на другую

=== "Android"

    Включите изоляцию для импортированной версии, если её миры, наборы и настройки должны быть отделены от версии из Google Play. Импортированным версиям изоляция часто нужна для запуска.

## Общие задачи управления версиями <Badge platform="windows" />

### Установка новой версии

Используйте страницу **Скачать**, затем вернитесь на страницу **Запуск** после завершения установки.

### Переименование версии

Используйте **Инстансы** или **Настройки инстанса**, чтобы дать настройке имя, отражающее её назначение, например `Release Выживание` или `Preview Тест`.

### Удаление версии

Удаляйте версии, которые вам больше не нужны, особенно тестовые установки Minecraft Preview, которые больше не актуальны.

::: warning Будьте осторожны перед удалением
Удаление версии может удалить управляемую среду для этой настройки. Сначала создайте резервную копию важных миров.
:::

### Создание ярлыка на рабочем столе

Используйте пункт **Создать ярлык экземпляра на рабочем столе** в меню рядом с кнопкой **Запуск**, чтобы создать ярлык для конкретной версии и запускать её напрямую.

## Рекомендуемая стратегия управления версиями <Badge platform="windows" />

- одна изолированная версия Minecraft Release для обычной игры
- одна изолированная версия Minecraft Preview только при необходимости
- одна временная тестовая версия для модов или устранения неполадок
