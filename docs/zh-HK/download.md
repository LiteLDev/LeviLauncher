# 下載

LeviLauncher 提供 Windows 版和 Android 版，下方已自動選中適合你裝置的版本。

=== "Windows"

    **要求：** Windows 10 或 11，以及從 Microsoft Store 獲得的正版 Minecraft 基岩版（GDK / UWP）。

    - [從 GitHub Releases 下載安裝程式](https://github.com/LiteLDev/LeviLauncher/releases/latest)
    - [藍奏雲鏡像](https://levimc.lanzoue.com/b016ke39hc) — 密碼 `levi`；GitHub 下載較慢時使用

    下一步：[在 Windows 上玩模組](https://levimc.org/tutorials/zh-Hant/play/play-with-mods/) · [版本管理](/zh-Hant/guide/version-management?platform=windows)

=== "Android"

    **要求：** Android 9.0 或更高版本的 ARM64 裝置，以及從 Google Play 安裝的 Minecraft 基岩版 1.21.80 或更高版本。

    - [從 GitHub Releases 下載 APK](https://github.com/LiteLDev/LeviLauncher-Android/releases/latest)

    下一步：[版本管理](/zh-Hant/guide/version-management?platform=android)

::: info iOS
LeviLauncher 沒有 iOS 版，我們也沒有開發 iOS 版的計劃。
:::
