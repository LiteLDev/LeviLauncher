# 设置与个性化

LeviLauncher 提供了较完整的设置页，可用于调整路径、外观、组件管理、隐私偏好与更新策略。

## 主要设置分区

应用当前会把设置分为多个区域，例如：

- 基础设置
- 个性化
- 第三方组件
- 其他设置
- 隐私
- 软件更新
- 关于

## 你可以调整什么

### 路径与存储

- 基础内容路径
- 托管文件所在的可写位置
- 更适合你磁盘布局的环境放置方式

### 外观

- 语言
- 明暗主题偏好
- 主题色行为
- 背景与视觉个性化项

#### 背景图片与界面材质

先在 **个性化 → 壁纸 → 背景图片** 中选择图片文件夹，再到 **个性化 → 材质与可读性** 中调整 **界面材质**，也就是壁纸与内容之间的那一层。导航栏、卡片、标签页、表单控件和浮层共用一套材质参数。日间、夜间材质分别保存，跟随当前主题自动应用；材质设置中的 **日间模式** / **夜间模式** 按钮仅用于选择要编辑和预览的配置。

| 设置 | 用途 |
| --- | --- |
| 均衡 | 默认预设：柔和磨砂并开启可读性保护 |
| 通透 | 更多图片细节透过卡片，关闭可读性保护，适合简单、低反差背景 |
| 纯色 | 卡片完全不透明并关闭卡片磨砂，背景仍在卡片外显示 |
| 界面不透明度 | 统一调节中性界面底色，文字、图标和按钮不会一起变透明 |
| 界面磨砂 | 统一调节面板、导航与浮层后方的模糊；图片模糊则影响整张背景 |
| 背景遮罩 | 日间用浅色、夜间用深色柔化背景，不同于图片亮度和图片不透明度 |
| 可读性保护 | 按主题、图片亮度、不透明度和模糊量设置保守的界面底色下限，并加强次要文字 |

实时预览与主界面共用当前加载的图片及渲染参数。可读性保护抬高卡片实际不透明度时，设置会显示实际应用值；这一计算不分析图片内容，也不上传图片。**重置当前主题** 仅恢复正在编辑的材质配置，不清除图片文件夹或另一主题的配置。

文件夹内有多张图片时，可点击 **换一张**。**顺序** 模式按文件名自然排序，**随机** 模式避免连续选中当前这张。未选图片、图片无法加载或图片不透明度为 0 时，界面恢复普通材质。系统要求更高对比度、减少透明效果或不支持背景磨砂时，界面使用纯色回退。

### 第三方组件

- [lip](https://github.com/LiteLDev/lip) 状态：检查、安装或更新，以及清理缓存

### 隐私

- 匿名使用统计（Microsoft Clarity），可随时关闭
- Clarity 条款与 Microsoft 隐私声明链接

### 更新

- 更新检查
- **接收测试版更新**，获取启动器预发布版本

## 推荐默认值

- 把托管文件放在一个可写且空间充足的磁盘位置
- 除非你想使用启动器预发布版本，否则保持 **接收测试版更新** 关闭
- 先让基础环境稳定，再去细调外观

## 什么时候值得重新检查设置

当你遇到这些情况时，建议回设置页看一遍：

- 想把安装迁移到另一块磁盘
- 遇到写权限错误
- 想在不同机器上使用不同外观或路径策略
- 需要排查下载或组件识别问题
