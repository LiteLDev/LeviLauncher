# 設定與個人化

LeviLauncher 提供完善的設定頁面，可用於調整路徑、外觀、組件管理、私隱偏好與更新策略。

## 主要設定分區

應用程式目前將設定分為多個區域，例如：

- 基礎設定
- 個性化
- 第三方元件
- 其他設定
- 私隱
- 軟體更新
- 關於

## 你可以調整什麼

### 路徑與儲存

- 基礎內容路徑
- 託管檔案所在的可寫入位置
- 更適合你磁碟佈局的環境放置方式

### 外觀

- 語言
- 淺色/深色主題偏好
- 主題色行為
- 背景與視覺個人化選項

#### 桌布與介面材質

先在 **個性化 → 桌布 → 背景圖片** 中選擇圖片資料夾，再到 **個性化 → 材質與可讀性** 中調整 **介面材質**，即桌布與內容之間的那一層。導覽列、卡片、分頁、表單控制項和彈出層共用同一套材質系統。日間與夜間材質分別儲存，並跟隨應用程式主題自動套用；材質編輯器中的 **日間模式** / **夜間模式** 按鈕只用於選擇要編輯和預覽的設定檔。

| 設定 | 作用 |
| --- | --- |
| 均衡 | 預設方案：柔和磨砂效果，並開啟可讀性保護 |
| 通透 | 更多桌布細節透過卡片顯示，並關閉可讀性保護；適合簡單、低對比度的圖片 |
| 純色 | 卡片完全不透明且不使用卡片模糊；桌布仍會在卡片以外顯示 |
| 介面不透明度 | 調整中性介面底色，文字、圖示和按鈕不會一同變淡 |
| 介面模糊 | 控制面板、導覽列與彈出層後方的模糊；圖片模糊則影響整張桌布 |
| 背景遮罩 | 日間模式以淺色、夜間模式以深色柔化桌布，與圖片亮度及不透明度分開調整 |
| 可讀性保護 | 根據主題、亮度、圖片不透明度與模糊程度套用保守的最低底色，並加強次要文字 |

即時預覽與主視窗共用已載入的圖片及渲染參數。當可讀性保護提高了卡片的實際不透明度時，編輯器會顯示實際套用的數值。這項計算不會分析或上傳圖片。**重設目前主題** 只會還原正在編輯的材質設定檔，不會清除圖片資料夾或另一個主題的設定檔。

資料夾內有多張圖片時，可使用 **換一張**。**順序** 模式按檔案名稱自然排序，**亂序** 模式會避免重複目前這張圖片。未選取圖片、圖片無法載入或圖片不透明度為 0 時，介面會恢復為一般表面。系統要求更高對比度、減少透明效果或不支援背景濾鏡時，介面會改用純色後備表面。

### 第三方元件

- [lip](https://github.com/LiteLDev/lip) 狀態：檢查、安裝或更新，以及清理快取

### 私隱

- 匿名使用統計（Microsoft Clarity），可隨時關閉
- Clarity 授權條款與 Microsoft 私隱聲明連結

### 更新

- 更新檢查
- **接收測試版更新**，以取得啟動器預發佈版本

## 建議預設值

- 將託管檔案存放在可寫入且空間充足的磁碟位置
- 除非你想使用啟動器預發佈版本，否則保持 **接收測試版更新** 關閉
- 先確保基礎環境穩定，再微調外觀設定

## 什麼時候值得重新檢查設定

當你遇到以下情況時，建議返回設定頁面檢視一遍：

- 想把安裝遷移至另一塊磁碟
- 遇到寫入權限錯誤
- 想在不同機器上使用不同的外觀或路徑策略
- 需要排查下載或組件識別問題
