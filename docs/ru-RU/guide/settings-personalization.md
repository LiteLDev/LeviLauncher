# Настройки и персонализация

LeviLauncher предоставляет обширный раздел настроек, позволяющий настроить пути, внешний вид, управление компонентами, параметры конфиденциальности и поведение обновлений.

## Основные разделы настроек

Приложение группирует настройки в несколько разделов, включая:

- Основные настройки
- Персонализация
- Сторонние компоненты
- Другие
- Конфиденциальность
- Обновления
- О программе

## Что можно настроить

### Пути и хранилище

- Базовый путь к контенту
- Путь с правами на запись для управляемых файлов
- Размещение среды в соответствии со структурой вашего диска

### Внешний вид

- Язык интерфейса
- Предпочтения по теме (светлая или темная)
- Поведение цветовой темы
- Параметры фона и визуальной персонализации

#### Обои и материал интерфейса

Выберите папку с изображениями в разделе **Персонализация → Обои → Фоновое изображение**, затем откройте **Персонализация → Материалы и читаемость**, чтобы настроить **Материал интерфейса** — слой между обоями и содержимым. Навигация, карточки, вкладки, элементы форм и всплывающие панели используют единую систему материалов. Светлый и тёмный профили сохраняются отдельно и применяются автоматически вместе с темой приложения; кнопки **Светлая тема** / **Темная тема** в редакторе материала только выбирают профиль для редактирования и предпросмотра.

| Параметр | Поведение |
| --- | --- |
| Сбалансированный | Предустановка по умолчанию: мягкое стекло с включённой защитой читаемости |
| Прозрачный | Сквозь карточки видно больше обоев, защита читаемости выключена; лучше всего подходит для простых малоконтрастных изображений |
| Сплошной | Непрозрачные карточки без размытия; обои остаются видимыми вне карточек |
| Непрозрачность интерфейса | Меняет нейтральный оттенок поверхностей интерфейса, не делая текст, значки или кнопки бледнее |
| Размытие интерфейса | Управляет размытием за панелями, навигацией и всплывающими панелями; размытие изображения влияет на все обои |
| Затемнение обоев | Приглушает обои светлым оттенком в светлой теме и тёмным оттенком в тёмной теме, независимо от яркости и непрозрачности изображения |
| Защита читаемости | Применяет умеренный минимальный оттенок с учётом темы, яркости, непрозрачности и размытия изображения, а также усиливает второстепенный текст |

Предпросмотр в реальном времени использует то же загруженное изображение и те же параметры отрисовки, что и главное окно. Если защита повышает фактическую непрозрачность карточек, редактор показывает применённое значение. Этот расчёт не анализирует и не загружает изображение. **Сбросить эту тему** восстанавливает только редактируемый профиль материала; папка с изображениями и профиль другой темы не затрагиваются.

Используйте **Следующее изображение**, если в папке несколько картинок. Порядок **Последовательно** использует естественную сортировку имён файлов; порядок **Случайно** не повторяет текущее изображение. Если изображение не выбрано, не может быть загружено или его непрозрачность равна 0, интерфейс возвращается к обычным поверхностям. При повышенной контрастности, уменьшенной прозрачности и неподдерживаемых фильтрах фона используются сплошные резервные поверхности.

### Сторонние компоненты

- Статус [lip](https://github.com/LiteLDev/lip): проверка, установка или обновление, а также очистка его кэша

### Конфиденциальность

- Анонимная аналитика использования (Microsoft Clarity), которую можно отключить в любой момент
- Ссылки на условия Clarity и заявление о конфиденциальности Microsoft

### Обновления

- Проверка наличия обновлений
- **Получать бета-обновления** — чтобы получать предварительные версии лаунчера

## Рекомендуемые значения по умолчанию

- Храните управляемые файлы на диске с правами на запись и достаточным свободным местом
- Оставьте **Получать бета-обновления** выключенным, если вам не нужны предварительные сборки лаунчера
- Меняйте параметры внешнего вида только после успешной настройки базовой конфигурации

## Когда следует проверять настройки

Проверяйте настройки, когда вы:

- Перемещаете установку на другой диск
- Сталкиваетесь с ошибками прав на запись
- Хотите настроить индивидуальную персонализацию для разных устройств
- Нужно устранить неполадки с загрузкой или обнаружением компонентов
