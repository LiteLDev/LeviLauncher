# 계정 및 빠른 실행

다음 기능은 Android 버전 LeviLauncher에서 제공됩니다.

## Xbox 계정

LeviLauncher는 런처 안에서 여러 Xbox 계정을 관리할 수 있습니다. Minecraft를 실행하기 전에 사용할 계정을 선택하면 게임이 원하는 계정으로 시작됩니다.

## 빠른 실행

빠른 실행(Quick Launch)은 Minecraft URI 동작을 사용해 자주 쓰는 흐름으로 바로 이동합니다. 동작에 따라 다음을 할 수 있습니다.

- 게임 화면 열기
- 서버에 연결하거나 서버 추가
- Realm 참가
- 로컬 월드 불러오기
- 명령 실행
