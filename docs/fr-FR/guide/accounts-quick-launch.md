# Comptes & Lancement rapide

Ces fonctionnalités appartiennent à la version Android de LeviLauncher.

## Comptes Xbox

LeviLauncher peut gérer plusieurs comptes Xbox dans le lanceur. Sélectionnez le compte voulu avant de lancer Minecraft pour que le jeu démarre avec la bonne identité.

## Lancement rapide

Le lancement rapide (Quick Launch) utilise les actions URI de Minecraft pour accéder directement aux parcours courants. Selon l'action, vous pouvez :

- ouvrir un écran du jeu
- vous connecter à un serveur ou en ajouter un
- rejoindre un Realm
- charger un monde local
- exécuter une commande
