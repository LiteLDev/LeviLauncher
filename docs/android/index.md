# Android Version

The Android version of LeviLauncher is an open-source launcher for Minecraft Bedrock Edition on Android. It works with the official game: import and launch your Google Play copy of Minecraft, manage isolated versions, switch accounts, organize worlds and packs, and extend the game with native mods.

::: tip Download
Get the latest APK from the [Download page](/download) or straight from [GitHub Releases](https://github.com/LiteLDev/LeviLaunchroid/releases/latest). Looking for the Windows version? Start with the [Windows guide](/guide/quick-start).
:::

## Features

- **Official game first:** built for legitimate Minecraft Bedrock Edition players; requires the official Google Play version of Minecraft.
- **Version isolation:** keep multiple game versions and their data separated so testing one setup does not disturb another.
- **Content management:** import, export, back up, and organize worlds, resource packs, and launcher data from one place.
- **Account switching:** manage multiple Xbox accounts in the launcher and switch between them before launching.
- **Quick Launch:** use URI actions to open specific Minecraft screens, connect to servers, or load a world faster.
- **Native mod support:** developers can use Preloader APIs to build native mods, receive input callbacks, install hooks, and apply patches.

## What this section covers

This section covers the Android version: installing the launcher, preparing an official Minecraft copy, managing versions, starting the game, and keeping player content organized. Developer-facing Preloader APIs are documented in the Developer part of the sidebar.

There is no iOS version of LeviLauncher, and none is planned.
