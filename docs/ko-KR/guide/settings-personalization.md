# 설정 및 개인화

LeviLauncher는 경로, 외관, 구성 요소 관리, 개인정보 보호 설정 및 업데이트 전략을 조정할 수 있는 비교적 완전한 설정 페이지를 제공합니다.

## 주요 설정 구역

앱은 현재 설정을 여러 영역으로 나눕니다. 예:

- 일반 설정
- 개인화
- 타사 구성 요소
- 기타
- 개인정보
- 업데이트
- 정보

## 무엇을 조정할 수 있나요?

### 경로 및 저장소

- 기본 콘텐츠 경로
- 호스팅 파일이 위치할 쓰기 가능한 위치
- 디스크 레이아웃에 더 적합한 환경 배치 방식

### 외관

- 언어
- 다크/라이트 테마 선호도
- 테마 색상 동작
- 배경 및 시각적 개인화 항목

#### 배경 이미지와 인터페이스 재질

**개인화 → 배경 이미지**에서 이미지 폴더를 선택한 다음, **개인화 → 재질과 가독성**을 열어 배경 이미지와 콘텐츠 사이의 레이어인 **인터페이스 재질**을 조정합니다. 탐색, 카드, 탭, 양식 컨트롤 및 팝업 표면은 하나의 재질 시스템을 공유합니다. 밝은 프로필과 어두운 프로필은 따로 저장되며 앱 테마에 따라 자동으로 적용됩니다. 재질 편집기의 **밝은 모드** / **어두운 모드** 버튼은 편집하고 미리 볼 프로필만 선택합니다.

| 설정 | 동작 |
| --- | --- |
| 균형 | 기본 프리셋: 가독성 보호가 켜진 부드러운 유리 효과 |
| 선명 | 카드 너머로 배경 이미지가 더 많이 보이며 가독성 보호는 꺼짐. 단순하고 대비가 낮은 이미지에 가장 적합 |
| 단색 | 카드 흐림이 없는 불투명 카드. 카드 바깥에서는 배경 이미지가 계속 보임 |
| 인터페이스 불투명도 | 텍스트, 아이콘, 버튼을 흐리게 하지 않고 인터페이스의 중립 표면 색조를 변경 |
| 인터페이스 흐림 | 패널, 탐색 및 팝업 표면 뒤의 흐림을 제어. 이미지 흐림은 배경 이미지 전체에 적용 |
| 배경 오버레이 | 이미지 밝기 및 불투명도와 별도로, 밝은 모드에서는 밝은 색조, 어두운 모드에서는 어두운 색조로 배경 이미지를 부드럽게 함 |
| 가독성 보호 | 테마, 밝기, 이미지 불투명도 및 흐림에 따라 보수적인 최소 색조를 적용하고 보조 텍스트를 강화 |

실시간 미리 보기는 불러온 이미지와 렌더링 매개변수를 기본 창과 공유합니다. 보호 기능으로 실제 카드 불투명도가 높아지면 편집기에 적용된 값이 표시됩니다. 이 계산은 이미지를 분석하거나 업로드하지 않습니다. **이 테마 초기화**는 편집 중인 재질 프로필만 복원하며, 이미지 폴더나 다른 테마의 프로필은 지우지 않습니다.

폴더에 여러 이미지가 있으면 **다음 이미지**를 사용하세요. **순차적** 순서는 자연스러운 파일 이름 정렬을 사용하고, **무작위** 순서는 현재 이미지가 반복되지 않도록 합니다. 이미지가 선택되지 않았거나, 이미지를 불러올 수 없거나, 이미지 불투명도가 0이면 인터페이스는 일반 표면으로 돌아갑니다. 고대비, 투명도 감소 및 지원되지 않는 배경 필터에서는 불투명한 대체 표면이 사용됩니다.

### 타사 구성 요소

- [lip](https://github.com/LiteLDev/lip) 상태: 확인, 설치 또는 업데이트, 캐시 정리

### 개인정보

- 익명 사용 분석(Microsoft Clarity), 언제든지 끌 수 있음
- Clarity 약관 및 Microsoft 개인정보처리방침 링크

### 업데이트

- 업데이트 확인
- **베타 업데이트 수신**으로 런처의 사전 릴리스 업데이트 받기

## 권장 기본값

- 호스팅 파일을 쓰기 가능하고 공간이 충분한 디스크 위치에 배치
- 런처의 사전 릴리스 빌드가 필요하지 않다면 **베타 업데이트 수신**을 끈 상태로 유지
- 기본 환경을 안정화시킨 후 외관을 세부적으로 조정

## 설정을 다시 확인할 가치가 있는 경우

다음과 같은 상황을 겪을 때 설정 페이지를 다시 확인하는 것이 좋습니다:

- 설치를 다른 디스크로 이전하고 싶을 때
- 쓰기 권한 오류가 발생할 때
- 다른 컴퓨터에서 다른 외관 또는 경로 전략을 사용하고 싶을 때
- 다운로드 또는 구성 요소 인식 문제를 해결해야 할 때
