# Аккаунты и быстрый запуск

Эти функции есть в версии LeviLauncher для Android.

## Аккаунты Xbox

LeviLauncher может управлять несколькими аккаунтами Xbox внутри лаунчера. Выберите нужный аккаунт перед запуском Minecraft, чтобы игра запустилась под ожидаемым профилем.

## Быстрый запуск

Быстрый запуск (Quick Launch) использует URI-действия Minecraft, чтобы сразу переходить к частым сценариям. В зависимости от действия можно:

- открыть экран игры
- подключиться к серверу или добавить его
- присоединиться к Realm
- загрузить локальный мир
- выполнить команду
