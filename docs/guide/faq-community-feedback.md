# FAQ, Community & Feedback

## Frequently asked questions
### Do I need to own Minecraft Bedrock?

Yes. LeviLauncher is designed to work with a legitimate licensed copy of Minecraft Bedrock Edition (GDK / UWP).

### Can I use LeviLauncher on macOS or Linux?

LeviLauncher has a **Windows** version and an **Android** version ([Android guide](/guide/quick-start?platform=android)). There is no macOS or Linux version.

### Is there an iOS version?

No. There are no plans for an iOS version of LeviLauncher.

### Should I use Release or Preview?

Use the Minecraft **Release** build for normal play. Choose the Minecraft **Preview** build only when you specifically want upcoming features and are comfortable with instability.

### Is isolation required?

No, but it is strongly recommended for testing, Minecraft Preview builds, and modded setups. Isolation is available for GDK versions and for UWP x64 versions 1.19.70.2 or later.

### Can I manage worlds and packs inside the launcher?

Yes. LeviLauncher includes content views for worlds, resource packs, behavior packs, skin packs, screenshots, and servers.

### Can I install mods?

Yes, but mod workflows are an advanced area. Start with a clean isolated version and test gradually.

### What does the Android version need?

Android 9.0 or later on an ARM64 device, and Minecraft Bedrock Edition 1.21.80 or later installed from Google Play. See [Requirements & Installation](./requirements-installation).

### Can I run several Minecraft versions on Android?

Yes. Import official Minecraft APKs to run other versions inside the launcher, and enable version isolation to keep their data separate.

## Reporting issues and feature requests
Use [GitHub Issues](https://github.com/LiteLDev/LeviLauncher/issues) for:

- reproducible bugs
- installation problems that are specific to LeviLauncher
- requests for clearer documentation
- feature suggestions with a concrete use case

Issues with the Android version go to [LiteLDev/LeviLaunchroid Issues](https://github.com/LiteLDev/LeviLaunchroid/issues).

## Before opening an issue

- update to the latest available launcher release
- try a clean isolated version
- temporarily disable new mods or packs
- write down the exact steps that caused the problem
