# Android 版 LeviLauncher

Android 版 LeviLauncher 是一个开源的 Android Minecraft 基岩版启动器。它依赖官方游戏运行：导入并启动你从 Google Play 安装的 Minecraft，管理隔离版本、账号、世界、资源包与备份，并通过原生模组扩展游戏能力。

::: tip 下载
从[下载页](/zh-CN/download)或直接从 [GitHub Releases](https://github.com/LiteLDev/LeviLaunchroid/releases/latest) 获取最新 APK。在找 Windows 版？请从 [Windows 版文档](/zh-CN/guide/quick-start)开始。
:::

## 功能

- **官方游戏优先：** 面向合法 Minecraft 基岩版玩家，要求设备上存在来自 Google Play 的官方 Minecraft。
- **多版本隔离：** 独立管理多个 Minecraft 版本和数据目录，测试、游玩、回退互不干扰。
- **内容管理：** 在启动器内导入、导出、备份和整理世界、资源包与启动器数据。
- **账号切换：** 在启动器内管理多个 Xbox 账号，并在启动前切换到需要使用的账号。
- **快速启动：** 使用 URI 操作直接打开指定游戏页面、连接服务器或加载本地世界。
- **原生模组支持：** 开发者可以通过 Preloader API 开发原生模组、接收输入回调、安装 hook 并应用 patch。
