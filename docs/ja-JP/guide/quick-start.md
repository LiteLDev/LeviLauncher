# 5 分で始める

ダウンロードからプレイまでの最短手順だけを知りたい場合は、まずこのページを読んでください。どのタブでも **Windows** か **Android** を選ぶと、ガイド全体がその選択に合わせて表示されます。

## 1. LeviLauncher のインストール

=== "Windows"

    - [GitHub Releases](https://github.com/LiteLDev/LeviLauncher/releases) ページまたは[藍奏雲ミラー](https://levimc.lanzoue.com/b016ke39hc)から LeviLauncher インストーラーをダウンロードします（藍奏雲のパスワードは `levi` です）。
    - Windows でインストーラーを実行します。
    - インストール中に WebView2 またはその他の依存関係が必要と表示された場合は、続行を許可してください。

=== "Android"

    - [GitHub Releases](https://github.com/LiteLDev/LeviLaunchroid/releases/latest) から最新の APK をダウンロードします。
    - 使用したブラウザーまたはファイルマネージャーからのアプリのインストールを許可し、APK をインストールします。
    - LeviLauncher を開き、ランチャーの利用規約と要求される権限を承認します。

## 2. Minecraft を準備する

=== "Windows"

    - **Minecraft Bedrock Edition** のライセンスを持つ Microsoft アカウントにログインします。
    - 現在の PC で Microsoft Store から少なくとも一度ゲームをインストール済みであることを確認します。
    - **Gaming Services** が利用可能であることを確認します（GDK バージョンで必要）。

    ::: warning 正規版が必要です
    LeviLauncher は Minecraft Bedrock (GDK / UWP) の管理に使用され、ゲームのライセンスを代替することはできません。
    :::

=== "Android"

    - このデバイスに **Google Play** から **Minecraft 統合版** 1.21.80 以降をインストールします。
    - LeviLauncher はこの公式版を信頼できるゲームの入手元として使います。ゲームのライセンスの代わりにはなりません。

## 3. バージョンを選ぶ

=== "Windows"

    - LeviLauncher を起動します。
    - サイドバーから **ダウンロード** に移動します。
    - **リリース** と **プレビュー** のどちらのビルドにするか、また **GDK** と **UWP** のどちらのパッケージにするかを選択します。
    - ここで **リリース** と **プレビュー** は Minecraft の正式版とプレビュー版を指します。
    - バージョンを選択し、インストールを開始します。

=== "Android"

    - バージョン（インスタンス）画面を開きます。
    - 起動したい Minecraft のバージョンを選ぶか、公式の Minecraft APK をインポートしてランチャー内で別のバージョンを実行します。

## 4. 隔離の有効化の可否を決定

=== "Windows"

    隔離は、そのバージョンのゲームデータを独立したワークスペースに入れ、デフォルトの AppData 環境と混在させなくなります。隔離は GDK バージョンと、1.19.70.2 以降の UWP x64 バージョンで利用できます。

    以下の場面で隔離の使用を推奨します：

    - Mod のテストをしたいが、メイン環境に影響を与えたくない場合
    - Minecraft 正式版とプレビュー版を分離したい場合
    - 遊び方ごとに異なるワールドやリソースパックを保持したい場合

=== "Android"

    インポートしたバージョンのワールド、パック、設定を Google Play 版と分けたい場合は、起動時にバージョン分離を有効にしてください。インポートしたバージョンは起動に分離が必要なことがよくあります。

## 5. インストール済みバージョンの起動

=== "Windows"

    - **起動** ページに戻ります。
    - インストールしたバージョンを選択します。
    - **起動** をクリックします。

    LeviLauncher が GameInput または Gaming Services の不足を報告した場合は、まずプロンプトに従って依存関係をインストールしてください。

=== "Android"

    - 起動画面に戻り、**起動** をタップします。
    - 起動に失敗した場合は、設定を変える前に失敗画面から起動ログを開いて原因を確認してください。
