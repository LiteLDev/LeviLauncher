# 常见问题、社区与反馈

## 常见问题

### 我必须拥有 Minecraft 基岩版正版吗？

是的。LeviLauncher 设计目标是配合**正版 Minecraft 基岩版（GDK / UWP）** 使用。

### 能在 macOS 或 Linux 上使用吗？

LeviLauncher 提供 **Windows 版**和 **Android 版**（[Android 版文档](/zh-CN/guide/quick-start?platform=android)），没有 macOS 或 Linux 版本。

### 有 iOS 版吗？

没有。我们没有开发 iOS 版 LeviLauncher 的计划。

### 我应该选正式版还是预览版？

日常游玩优先选 Minecraft **正式版（Release）**。只有你明确需要体验即将到来的内容，并且能接受不稳定时，再考虑 **预览版（Preview）**。

### 隔离是必须的吗？

不是必须，但对测试、Minecraft 预览版（Preview）环境和模组环境来说非常推荐。GDK 版本以及 1.19.70.2 及以上的 UWP x64 版本支持隔离。

### 能在启动器里管理世界和资源包吗？

可以。LeviLauncher 提供世界、资源包、行为包、皮肤包、截图与服务器列表等内容视图。

### 能安装模组吗？

可以，但这属于高级工作流。建议先从一个干净的隔离版本开始，逐步测试。

### Android 版需要什么？

ARM64 设备上的 Android 9.0 或更高版本，以及从 Google Play 安装的 Minecraft 基岩版 1.21.80 或更高版本。参见[系统要求与安装](./requirements-installation)。

### Android 上能运行多个 Minecraft 版本吗？

可以。导入官方 Minecraft APK 即可在启动器内运行其他版本，启用版本隔离可让它们的数据相互独立。

## 如何反馈问题与功能建议

请使用 [GitHub Issues](https://github.com/LiteLDev/LeviLauncher/issues) 反馈：

- 可复现的 Bug
- 与 LeviLauncher 明确相关的安装问题
- 对文档表达不清的改进建议
- 带有明确使用场景的功能请求

Android 版的问题请提交到 [LiteLDev/LeviLaunchroid Issues](https://github.com/LiteLDev/LeviLaunchroid/issues)。

## 提交 Issue 之前建议先做

- 更新到最新可用版本
- 用一个干净的隔离版本做一次对照测试
- 暂时禁用新加入的模组或资源包
- 记录导致问题出现的精确步骤
