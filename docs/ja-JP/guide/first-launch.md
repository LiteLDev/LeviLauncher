# 初回起動

LeviLauncher を初めて開くと、アプリはデバイスと Minecraft がバージョン管理の準備ができているかを確認します。

## 何が表示されるか

=== "Windows"

    初回起動時、LeviLauncher は以下の確認を行う場合があります：

    - Gaming Services が利用可能か確認 (GDK)
    - GameInput が利用可能か確認 (GDK)
    - ネイティブ Mod ローダーに必要な Visual C++ ランタイムがインストールされているか確認
    - Minecraft Bedrock (GDK / UWP) 環境が準備できているか検証
    - 重要なコンポーネントが不足している場合のガイダンスやプロンプトの表示

=== "Android"

    初回起動時、LeviLauncher は次のことを行う場合があります。

    - ランチャーの利用規約への同意を求める
    - 必要な権限を要求する
    - Google Play の公式 Minecraft（1.21.80 以降）がインストールされているか確認する
    - 古いランチャーのデータディレクトリを移行する

## 一般的な初回起動フロー

=== "Windows"

    1. LeviLauncher を開く。
    2. ランチャーのガイダンス情報を読む。
    3. 不足している前提コンポーネントをインストールまたは修復する。
    4. ランチャーに戻り、ステータスを再確認する。
    5. 条件を満たすと **ダウンロード** ページへ進む。

=== "Android"

    1. LeviLauncher を開きます。
    2. 利用規約に同意し、要求された権限を許可します。
    3. ランチャーが古いデータを移行している場合は、完了するまで待ちます。ワールド、パック、設定が再び使えるようになるまで、古いディレクトリを削除しないでください。
    4. バージョン画面に進みます。

## コンポーネント不足の提示時 <Badge platform="windows" />

### Gaming Services

Gaming Services が不足しているか破損している場合、LeviLauncher は Microsoft Store でのインストールまたは修復を促す場合があります。

### GameInput

GameInput が不足している場合は、プロンプトに従って必要な redistributable をインストールしてください。

### Minecraft Bedrock が検出されない

以下を確認してください：

- 現在の Microsoft アカウントにゲームのライセンスがあるか
- 現在の PC で Microsoft Store からゲームがインストールされているか
- 公式ライセンスフローをバイパスしてランチャーを使用しようとしていないか

## 新規ユーザー向けのおすすめ初期設定

- まず隔離された正式版（Release）バージョンを使用する
- ダウンロードとコンテンツのパスを書き込み可能なディスク場所に置く
- 最初に正常なクリーン起動ができるまで、大量の Mod をインポートしようとしない
